# Task API

A backend REST API built with Node.js, Express, and MongoDB.

## Features
- Create tasks and save them to a cloud database
- Fetch all tasks

## Tech Stack
- Node.js
- Express.js
- MongoDB (Mongoose)
- Dotenv

## How to run locally
1. Clone the repo
2. Run `npm install`
3. Create a `.env` file and add your `MONGODB_URI`
4. Run `node server.js`
